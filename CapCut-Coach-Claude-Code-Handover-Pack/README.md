# CapCut Coach Claude Code Handover Pack

This folder contains the complete build handover for a private, local CapCut Coach application for one beginner using CapCut Premium on an M2 Mac.

Start with `00_READ_ME_FIRST.md`, then read every numbered file in order. The ready-to-paste first Claude Code prompt is in `07_START_PROMPT_FOR_CLAUDE_CODE.md`.

Files `09_API_CONFIG_AND_STORAGE_CONTRACT.md` and `10_RISK_REGISTER.md` turn the design into concrete implementation contracts and release gates. The owner can follow `11_OWNER_QUICKSTART.md`. Files `12`–`14` fix the cost ceiling, Drive/large-media behaviour and premium beginner interface. Claude Code must read the entire pack even though the starting prompt appears earlier in the sequence.

The pack deliberately distinguishes:

- what is safe and proven;
- what is feasible but must be tested on the exact CapCut version;
- what is a permanent fallback;
- what “automatic” genuinely means;
- which repositories may be reused and which should be avoided.

Do not skip the Phase 0 CapCut compatibility canary.
