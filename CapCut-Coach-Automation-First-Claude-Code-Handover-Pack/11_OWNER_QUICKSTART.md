# Owner Quickstart

## What you need

- Your M2 Mac with about 77GB currently free.
- Claude Code signed into the Claude Max plan you already have.
- This handover folder.
- A small test script and copied test footage. CapCut Free is optional.

## Build it once

1. Put the handover folder in a normal local development folder, not inside a synced Drive folder.
2. Open Terminal in its parent folder and start Claude Code.
3. Paste the prompt from `07_START_PROMPT_FOR_CLAUDE_CODE.md`.
4. Let Claude Code inspect, plan, implement and test the free local-render proof.
5. When it needs evidence from your Mac, follow only the exact action it asks for. It should not ask you for a CapCut project or old finished videos to reach the first milestone.

The first milestone is complete only when a script and raw folder produce Clean/Enhanced/Bold previews and a valid final MP4 locally with the originals unchanged.

## Normal daily use

1. Open CapCut Coach like a normal Mac app—no Terminal.
2. Press **Create Video**.
3. Choose the script and raw folder, or an approved Google Drive folder.
4. Confirm Coach's automatic reel/shot grouping if it found any ambiguity.
5. Let it analyse in the background; only one heavy job runs at a time.
6. Compare the three previews and choose one or tap a simple change.
7. Press **Render Final**.
8. Optionally press **Open in CapCut Free** for a touch-up and follow the one next-step card.
9. Approve the outcome for learning.
10. Use **Finish & Free Space** only after checking the exact local file list. It never deletes cloud files and never empties Trash.

## Style learning

Start with Coach's built-in judgment. Every chosen preview and approved final improves the profile. Later you may add finished examples with their matching raw footage and scripts; five examples prove the pipeline, about 10 begin useful personalisation and 15–20 usually provide much stronger evidence. Keep poor examples marked **Do Not Copy**.

## Storage and performance

Use Drive for Desktop in Stream Files mode where practical. Coach stages only what it needs locally. Keep one active large job, warn below 30GB free and pause heavy new work before free space reaches 15GB. Plug in power for long renders. Quiet mode pauses heavy work while CapCut is open; Balanced mode is the default.

## Optional CapCut connection

File-based CapCut Free handoff needs no project access. Direct project writing is experimental and off. If you later choose to develop it, use only a disposable duplicate and complete the separate ten-run compatibility canary; a failure must leave the normal local renderer unaffected.
