# Phase 0 Evidence

**Goal.** Determine what is safely possible on the owner's exact M2 Mac and
CapCut build before committing to direct draft automation.

**Environment where this was prepared.** Linux CI container (not the target Mac).
Therefore every Mac/CapCut-dependent run below is **BLOCKED BY EVIDENCE**, not
passed. The *tooling* to gather the evidence is implemented and unit-tested.

## What was built (runs anywhere)
- `scripts/doctor.sh` — environment doctor. Detects OS, chip, RAM, free space,
  Python/Node/uv/pnpm/FFmpeg/Xcode CLT, Claude CLI presence (never prints
  secrets), and — on macOS — the CapCut bundle/version/build/source and project
  roots. On Linux it reports each Mac-only check as `blocked`.
- `apps/backend/capcut_coach/capcut/detect.py` — pure-Python CapCut bundle /
  `Info.plist` / app-source detection + project-root discovery. Unit-tested
  against a synthetic `Info.plist` fixture.
- `apps/backend/capcut_coach/capcut/compatibility.py` — the compatibility
  registry model + status state machine (`READ_ONLY` … `BLOCKED`), with the rule
  that any version change drops status to `CANARY_REQUIRED`. Unit-tested.
- `apps/backend/capcut_coach/capcut/canary.py` — caption-only ten-run canary
  procedure. It **refuses** on write-guarded/unsupported versions and requires a
  disposable duplicate + full backup/restore. The mutation step is disabled off
  the tested version. Logic unit-tested; live run blocked.
- `apps/mac-bridge/` — Swift read-only Accessibility/version probe (macOS only).
- `scripts/benchmark.py` — M2 stage benchmark harness.

## Commands run in CI
```
$ ./scripts/doctor.sh            # → all CapCut/Mac checks reported "blocked (not macOS)"
$ ./scripts/test.sh              # → backend unit tests pass (see docs/phase-evidence/P1.md)
```

## Gated runs (must happen on the Mac)
| Check | Status |
| --- | --- |
| CapCut bundle/version/build/source detection | ⛔ BLOCKED (needs CapCut) |
| Read-only `info`/`version`/`diagnose`/`lint` on a canary duplicate | ⛔ BLOCKED |
| Caption-only mutation canary, ten consecutive runs | ⛔ BLOCKED |
| Exact-hash restore after each canary run | ⛔ BLOCKED |
| Accessibility probe of CapCut panels | ⛔ BLOCKED |
| M2 stage benchmark (proxy/audio/whisper/preview) | ⛔ BLOCKED |

## Decision
Direct CapCut writes remain **disabled**. Effective compatibility status:
`CANARY_REQUIRED`. Read-only inspection and safe handoff proceed.

## Minimum user action required to unblock
On the Mac, create **one disposable 5-second CapCut project** with one video and
one caption, close CapCut, then run `./scripts/doctor.sh` and the
`/api/v1/capcut/canary` flow. Exact steps are printed by the doctor.
