# Phase 2–4 Evidence

## Phase 2 — Media intake, cache, transcription, scripts
Built: content-addressed cache (`media/cache.py`), FFmpeg/ffprobe wrappers with
graceful `FFmpegUnavailable` degradation (`media/ffmpeg.py`), whisper.cpp
transcriber + checksum-verified model manager (`media/transcription.py`), SRT
writer/validator (`media/srt.py`), safe script-pack parser with zip-bomb +
traversal guards (`scripts_pack/parser.py`), path-safety layer (`security.py`).

Tests: SRT UTF-8/non-overlap (F4), cache determinism + config-sensitivity +
pinned-survives eviction (F3, P6), streaming hash, script-pack reel/overlay/
end-card parsing with retained unknown lines (F4A), traversal rejection (S7).

⛔ Blocked in CI: real FFmpeg proxy/audio runs and whisper.cpp transcription
(binaries/models absent) — wrappers are exercised for their guard paths only.

## Phase 3 — Deterministic dialogue rough cut
Built: transcript model (`transcript.py`), phrase/silence/filler/repeat/restart
detection with dramatic-pause preservation and clip-risk flags
(`roughcut/detect.py`), edit-plan schema in integer microseconds + validator
(`schemas/edit_plan.py`), duration-candidate builder (`roughcut/plan.py`).

Tests (F5, F6, exit gate): filler flagged-not-deleted; long silence removed but
dramatic pause kept; false restart flagged; candidates valid, non-overlapping,
in-bounds, and respecting target duration; all edit-plan invariants.

## Phase 4 — Claude decision layer
Built: `ClaudeDecisionProvider` + `SubprocessClaudeProvider` (argument-array
`claude -p --output-format json`), JSON-Schema validation with semantic id/range
checks and one repair retry, decision cache, `AllowanceMeter` hard stop, and
deterministic fallbacks for every decision (`claude/`).

Tests (F8, S8): valid response accepted + cached (no repeat call); unknown id →
repair → fallback; malformed JSON → fallback; overage guard hard-stops with zero
model calls; disabled provider uses fallback only. Confirms the app produces a
deterministic result with Claude fully disabled (CLAUDE.md #13) and that model
output never reaches files or commands.
