# Phase 1 Evidence — Local application foundation

## Built
- FastAPI service (`capcut_coach/app.py`) bound to `127.0.0.1`, bearer-token
  guarded on every route except `/api/v1/health`.
- Typed config + macOS-standard storage layout (`config.py`) with a CI fallback
  via `COACH_DATA_DIR`.
- SQLite **WAL** with forward-only migrations and a pre-migration backup (`db.py`).
- Persisted job state machine + queue with idempotency keys, heavy-job
  serialisation, and crash recovery (`jobs.py`).
- Project repository — analysis-only, never touches source media (`projects.py`).
- Structured logging with home-path/secret redaction (`logging_setup.py`).
- Routers: system (status/doctor/storage/permissions), projects, jobs.
